# 04 · 市场与商业模式

> 这一章服务于"小挑"（创业计划竞赛）的商业计划书；若打"大挑"（课外学术科技作品竞赛），本章压缩为"应用前景"一节即可。
> 写作原则：**不要吹市场规模，要讲清楚"第一批付费客户是谁、为什么今天就愿意掏钱"。**

---

## 一、切入逻辑：先做滩头，不做平台

学生团队最大的错误是"面向所有 3D 用户"。**必须选一个高频、痛点明确、决策链短的滩头市场。**

### 滩头一：AI 生成模型的"打印就绪化"（推荐首选）

**为什么是它**：
- 文生 3D（TripoSR / InstantMesh / MeshGPT / DeepMesh 等）爆发式增长，产出海量模型
- 这些模型**绝大多数不能直接打印**：非水密、法线翻转、自交、壁太薄
- 用户画像清晰：AI 建模爱好者 + 3D 打印玩家，**高度重合，且活跃在同一个社区**
- 痛点高频（每次生成都要处理）、决策链极短（个人直接付费）、传播性强（晒成品）
- **蹭上 AIGC 叙事，商业故事性极强——这对"小挑"的商业模式创新评分很有利**

**产品形态**：Blender 插件 / 网页工具 / 切片器插件，"拖进去 → 一键打印就绪"。
**定价**：免费版限面数引流 → 专业版订阅。

### 滩头二：3D 打印服务商与手办工作室

**为什么是它**：
- **最高频**：每天处理几十个客户模型，每个都可能需要修复
- **痛点最痛**：现有软件修完丢纹理，得回头找客户要素材或手工重做；大件手办必须分块打印，接缝强度是口碑问题
- **价格敏感**：Magics ¥25,000+/模块、Netfabb ¥16,000/年、Geomagic ¥80,000+，中小服务商用不起
- **决策链短**：老板一个人拍板

**产品形态**：桌面 GUI + 批量处理 + 云 API。
**定价**：¥1,999/年/席（对标 Netfabb 约 ¥16,000，约 1/8）。

### 滩头三：医疗器械（高客单价，二期切入）

- 牙科种植导板、骨科外固定支架、手术导板 → **分块 + 强度是关键安全问题**
- 该领域对"强度可预测"的付费意愿最高，且需要合规文档
- 需要二类医疗器械相关资质与临床验证 → **不宜作为学生项目的首发场景**，作为商业化二期和"市场空间"论据

### 后续扩展场景

| 场景 | 需求 | 说明 |
|---|---|---|
| 工业逆向工程 / 质检 | 扫描破损件修复、CAD 衔接 | 客单价高，销售周期长 |
| 数字孪生 / 文物数字化 | 大场景多视扫描的拼接缝消除 | 项目多、经费足，适合做标杆案例 |
| 消费级创客 | 免费/低价版 | 做流量与数据飞轮 |

## 二、竞品对照（商业计划书核心一页）

| 维度 | Materialise Magics | Autodesk Netfabb | Geomagic Wrap | Blender 3D-Print Toolbox | OptCuts/Autocuts | **愈缝 SeamHeal** |
|---|---|---|---|---|---|---|
| 定位 | 工业级增材制造前处理 | 增材制造修复与仿真 | 逆向工程 | 免费检测插件 | 学术参数化 | **修复+接缝一体化** |
| 价格 | ¥25,000+/模块 | ~¥16,000/年 | ¥80,000+ 买断 | 免费 | 免费（无产品） | **¥1,999/年** |
| 价格问题 | 大版本升级另收费，培训 ¥20,000+ | 强制订阅，云算力另计 | 年维护 15%，加密狗丢失按全价补 | 仅检测不修复 | 无产品化 | 订阅制，学生/创客免费 |
| 几何修复 | ✓ | ✓ | ✓ | ✗ | ✗ | ✓ |
| **纹理保持** | ✗ 常丢失 UV | ✗ 常丢失 UV | 部分 | — | — | **✓** |
| **接缝优化** | ✗ | ✗ | 部分 | ✗ | 仅 UV 缝 | **✓ 三域** |
| **分块+接头+强度预测** | ✗ | ✗ | ✗ | ✗ | ✗ | **✓** |
| 性能短板 | 数千万面需 64GB 内存 | 4K 贴图模型卡顿 | 重网格化可能需一天 | — | 大网格内存爆炸 | 目标 50 万面 <3min |

> ⚠️ **所有对比结论必须自测取证**。计划：每个竞品各准备 3 个测试模型（含纹理破损件、大孔洞件、需分块件），录屏记录全过程，形成《竞品实测报告》作为申报书附件。**这份报告的说服力远超任何文献引用。**

## 三、商业模式

### 3.1 收入结构（四层，逐层提高客单价）

| 层级 | 产品 | 客户 | 定价 | 作用 |
|---|---|---|---|---|
| 免费 | Blender 插件（限面数/限功能） | 创客、学生 | ¥0 | 引流、收集缺陷数据、建立口碑 |
| 订阅 | 专业版桌面软件 | 打印服务商、工作室 | ¥1,999/年/席 | **现金流主力** |
| 云服务 | 修复/接缝 API 按次 | 3D 模型平台、打印平台、扫描设备厂商 | ¥0.5–5/模型 | 规模化、嵌入他人工作流 |
| 企业 | SDK 授权 + 私有化部署 | 医疗器械、工业、军工 | ¥10–50 万/年 | 高毛利 |

### 3.2 增长飞轮（这是"商业模式创新"的得分点）

```
免费插件触达创客 → 用户上传破损模型 → 积累真实缺陷数据
        ↑                                        ↓
   口碑传播  ←  修复效果可视化分享  ←  数据反哺模型训练与策略优化
```

**关键在于**：免费版不只是在引流，它在**持续收集真实世界的缺陷分布**——这是竞品拿不到的**数据壁垒**。Netfabb/Magics 是闭源桌面软件，无法形成这样的数据回流。

> ⚠️ 必须写明**数据合规策略**：仅收集用户明确授权的匿名化几何统计数据；提供完全离线的本地模式。**这一点在答辩中很可能被问，也是"小挑"评审关注的合规要点。**

### 3.3 成本结构

| 成本项 | 说明 |
|---|---|
| 研发 | 学生团队人力成本低，主要是时间 |
| 算力 | 训练与云服务 GPU 成本（可用学校资源 + 学生优惠） |
| 实验 | 打印耗材、试验机机时、第三方检测 |
| 合规 | 软著、专利、查新报告费用 |
| 推广 | 社区运营、3D 打印展会、B站/抖音内容营销 |

**优势**：学生团队的人力成本优势使我们可以用**远低于竞品的价格**切入，且仍能维持高毛利（软件边际成本近零）。

## 四、壁垒（回答"如果 Magics 明天做这个功能怎么办"）

这是商业计划书里必答的一问，必须准备三个层次的答案：

1. **数据壁垒**：SeamBench 数据集 + 真实打印强度实验数据库 + 免费版回流的海量真实缺陷样本。**商业软件厂商没有动力去做这种脏活累活，而这对模型质量是决定性的。**
2. **算法壁垒**：三域统一接缝能量框架 + 应力感知接头生成，已申请专利。大厂要绕过需要时间。
3. **生态壁垒**：与切片器深度集成（Cura/PrusaSlicer/OrcaSlicer）+ 与扫描设备厂商绑定（把修复引擎嵌入扫描仪输出流程）。**一旦嵌入硬件工作流，替换成本极高。**
4. **（可选）垂直壁垒**：在医疗器械场景做临床验证与合规文档积累，这是大厂不愿为小市场投入的。

**诚实补充**：如果 Autodesk 决定把该功能并入 Netfabb，单点技术优势会被削弱。因此**必须在 12–18 个月内把"接缝"这个词和我们的品牌绑定，并拿下垂直行业的标杆客户**。这个风险要主动说，比被评委问出来好。

## 五、财务与里程碑（简化三年）

| 年度 | 阶段 | 关键动作 | 收入预期 |
|---|---|---|---|
| 第 1 年 | 产品验证 | 插件上线、1000+ 免费用户、20 家付费服务商、完成 3 家标杆案例 | 种子期，以验证为主 |
| 第 2 年 | 规模复制 | 企业 SDK 签约、医疗器械试点、社区规模化 | 首轮收入成型 |
| 第 3 年 | 建立标准 | SeamBench 成为领域参考、接缝强度预测成为行业指标 | 稳定营收 |

> ⚠️ **不要编造收入数字。** 学生项目在财务预测上被追问细节的概率极高，一旦答不上来就全线崩塌。**正确做法：给出清晰的单位经济模型（客单价、获客成本、毛利结构）+ 保守的客户数量假设，并明确标注这是假设而非承诺。**
