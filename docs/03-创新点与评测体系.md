# 03 · 创新点与评测体系

> 评委只信两样东西：**对比对象** 和 **数字**。
> 每条创新点的写法都必须是：*别人做不到 X，我们做到了，量化提升是 Y，证据是 Z。*

---

## 一、四条创新点（论证式写法）

### 创新点 1 · 纹理保持的联合修复（Texture-Preserving Repair）

**现有做法的失败**：Netfabb / Magics 修复时会删除问题三角面，并用**不含 UV 坐标的新面**替换，导致模型修复成功但纹理丢失。这是专业 3D 打印服务商社区反复记录的问题，也是"先贴图后修复"工作流的致命伤。

**我们的做法**：把 UV 与纹理纳入修复的求解变量，而不是修复后的附属品。
- 补片 UV 由孔洞边界 UV 做**调和插值**生成（稀疏线性系统，边界固定）
- 补片纹理内容用 PatchMatch/FMM 补全，再与原纹理做**泊松融合**消色差
- 隐式重建路径下，把重建面的边界顶点**精确复用**原网格边界顶点，避免裂缝与 T 型接头

**量化对比**：

| 指标 | Netfabb / Magics | 愈缝（目标） |
|---|---|---|
| 修复区 UV 保留率 | 显著劣化甚至完全丢失 | **> 99%** |
| 修复区纹理 PSNR | 不可用（UV 丢失） | **> 30 dB** |
| 修复区纹理 SSIM | 不可用 | **> 0.95** |
| 模型形变（Hausdorff，非修复区） | 存在局部塌陷/变形记载 | **< 0.1% 包围盒对角线** |

**证据形态**：修复前后对比图 + 同一破损模型下三家工具的并排结果 + 录屏。**这一页的视觉效果最好，适合放在答辩前 3 分钟。**

### 创新点 2 · 跨几何/纹理/力学的统一接缝能量框架

**现有做法的割裂**：
- OptCuts（TOG 2018，UV 接缝优化 SOTA）只优化参数化域：在失真上界约束下最小化接缝长度
- Autocuts（SIGGRAPH Asia 2017）只做接缝代价与失真能量的加权
- 商业修复软件完全不考虑接缝
- 制造接缝由工程师凭经验手工处理，无任何工具支持

**没有任何工作把这三个域放进同一个优化问题。**

**我们的做法**：定义统一的接缝不连续能量（见 [README](../README.md) 第二节），在接缝曲线/面上同时惩罚几何法线不连续、位置不连续、颜色不连续、力学不连续：

```
E_seam(Γ) = ∫_Γ [ w_g‖Δn‖² + w_p‖Δx‖² + w_t‖Δc‖² + w_m‖Δσ‖² ] ds
```

并在此基础上求解 `min E_seam + λE_fidelity + μE_manufacturability`，约束为拓扑合法性与可制造性。

**为什么这是创新而不是拼凑**：因为三个域共享同一个**接缝场（Seam Field）**数据结构，修复、参数化、分块三个环节读写的是同一份接缝状态，从而实现真正的联合优化（例如：为了力学强度需要在某处加厚，这会改变局部曲率，进而影响 UV 失真的分配——这些耦合在割裂流程里根本无法表达）。

**量化对比**：

| 指标 | OptCuts / Autocuts | 商业修复软件 | 愈缝（目标） |
|---|---|---|---|
| 优化域数量 | 1（纹理） | 0（接缝） | **3（几何+纹理+力学）** |
| 接缝处法线角差（G1 偏差） | 不涉及 | 不涉及 | **< 5°** |
| 接缝可见度（AO 加权缝长占比） | 无此指标 | 无 | **降低 30%+** |
| 力学强度保持率 | 不涉及 | 不涉及 | **> 95%** |

> ⚠️ **风险提示**：这一条在答辩时最容易被质疑"你们是不是把三件事硬凑成一个概念"。
> **准备方式**：必须给出至少一个**耦合案例**——即"单独优化某一个域会导致另外两个域变差，只有联合优化才能同时满足"，并展示三组对比结果（只优化几何 / 只优化纹理 / 联合优化）。**有耦合案例，这条创新就站得住；没有，就会被当成包装。**

### 创新点 3 · 应力感知的分块与互锁接头自动生成

**现有做法的空白**：目前**没有任何工具**能自动完成"分块位置决策 + 接头生成 + 打印方向优化 + 强度预测"。这部分 100% 由工程师手工完成。开源切片器（Cura/PrusaSlicer）的分块功能只是把模型切成两半，不考虑应力、不生成接头、不优化朝向。

**痛点规模（关键数据）**：
- 拼接但不处理接缝：平均破坏拉力 **215.3 N**
- 完整件：平均破坏拉力 **280.7 N**
- **强度下降 23.3%**
- 接缝处 **> 0.1 mm 凸起**、**> 0.2 mm 缝隙**，断裂基本沿接缝发生
- 公开资料显示，采用接缝错位均摊方案后强度损失可降至 **2.5% 以内**

> ⚠️ **这组数字必须由我们自己复现或核实原始出处。** 计划：设计三组标准拉伸试件（完整件 / 未处理接缝 / 优化后接缝，各 n≥5），万能试验机实测。**自己测出来的数据是最好的申报材料，也直接变成第 3 条创新的证据。**

**我们的做法**：
1. 简化 FEM 应力场 / 主应力方向分析 → 识别临界截面
2. 分块面位置与朝向的约束优化（避开高应力区、避开特征线、满足成形空间、利用 FDM 各向异性）
3. 自动生成互锁接头（销孔 / 燕尾榫 / 球窝 / 卡扣），参数由局部壁厚与喷嘴直径推导
4. **均摊错位接缝**：把单一截面的接缝分散到不同高度与角度
5. 每块独立优化打印方向，直接输出切片预设
6. 层间接触面积 → 各向异性简化强度模型 → 破坏载荷预测（用步骤 1 的实验数据标定）

**量化对比**：

| 指标 | 手工经验方案 | 开源切片器分块 | 愈缝（目标） |
|---|---|---|---|
| 接缝强度保持率 | 76.7%（未处理） | 不适用 | **> 95%** |
| 装配对位误差 | 依赖人工，不可复制 | 无定位结构 | **< 0.1 mm** |
| 分块方案耗时 | 2–4 小时人工 | 秒级但无质量 | **< 5 min 自动** |
| 强度预测能力 | 无 | 无 | **预测误差 < 15%**（经实验标定） |

**答辩杀手锏**：现场展示**断裂后的实物试件对比**——未处理接缝的试件断在接缝上，优化后接缝的试件断在母材上。**一个实物胜过十页 PPT。**

### 创新点 4 · SeamBench 基准与可复现评测协议

**现有数据集的缺口**：Thingi10K、ABC、ModelNet、Objaverse 都只提供**干净或天然缺陷**的模型，**没有任何数据集标注"接缝"**，也没有任何标准协议评估修复后模型的**可制造性**。现有评估用 Chamfer Distance / Hausdorff 这类纯几何指标，**无法回答"打印出来会不会断"**。

**我们的贡献**：
1. 构建 **SeamBench**：从 Thingi10K/ABC 采样 + 程序化注入四类缺陷（孔洞、自交、非流形边、接缝错位），并为带纹理模型标注 UV 信息
2. 定义 **6 项跨域指标**（见第二节），尤其是**接缝强度保持率**这一新指标
3. 提供完整评测脚本与基线结果，做到**可复现**

**为什么这算创新**：在挑战杯语境下，"提出一套被同行可用的评测标准"是**最有学术分量**的贡献类型，而且**可以被查新报告支撑**。同时它让第 1–3 条创新的效果变得可验证——**没有基准，前面三条创新就都是自说自话。**

## 二、评测指标体系（6 项，分三域）

| 域 | 指标 | 定义 | 目标值 | 对比基线 |
|---|---|---|---|---|
| 几何 | **水密率 / 流形率** | 处理后通过流形性与水密性检测的模型占比 | 100% | MeshFix, ManifoldPlus |
| 几何 | **Chamfer Distance / Hausdorff** | 修复区与真值（合成数据的孔洞前原始模型）的距离 | 优于 SPSR | SPSR, Point2Mesh, MeshFix |
| 几何 | **特征保持误差 / 非修复区形变** | 非修复区域顶点位移最大值 | < 0.1% 包围盒对角线 | Netfabb, Magics |
| 纹理 | **UV 保留率 / 纹理 PSNR / SSIM** | 修复区 UV 与纹理的保真程度 | >99% / >30dB / >0.95 | Netfabb, Magics |
| 几何+纹理 | **接缝可见度** | 接缝曲线按环境光遮蔽加权的长度占比 | 降低 30%+ | OptCuts, Autocuts, xatlas |
| **制造** | **接缝强度保持率** ★ | 优化后拼接件破坏载荷 / 完整件破坏载荷 | **> 95%** | 未处理接缝（76.7%） |

**效率指标（工程约束）**：单模型处理时间（50 万面 < 3 min）、峰值内存。

### 2.1 合成数据评估（几何与纹理域）

做法：从干净模型中**程序化挖洞/破坏**，保留原始模型作为真值，即可精确计算 CD/Hausdorff/PSNR。
- 优点：有真值、可大规模批量、可复现
- 缺点：注入的缺陷分布可能与真实扫描件不同 → **必须补充真实数据评估**

### 2.2 真实数据评估（制造域 + 可信度）

- 真实扫描件：联系 3D 打印服务商/文博单位，用"免费修复服务"换取数据使用授权
- 断裂残件：自建或收集
- **力学实验**：三组标准试件 × n≥5，万能试验机拉伸，统计破坏载荷与断裂位置

## 三、实验设计（直接对应创新点，可写进论文）

| 实验 | 目的 | 设计 | 对应创新点 |
|---|---|---|---|
| E1 修复质量 | 修复后的几何保真 | SeamBench 合成缺陷，对比 MeshFix/SPSR/Netfabb，报告 CD/水密率/形变 | 创新 1、4 |
| E2 纹理保持 | **证明不丢纹理** | 带 UV 的破损模型，对比 Netfabb/Magics，报告 UV 保留率与 PSNR | **创新 1（核心）** |
| E3 接缝可见度 | 缝位优化的有效性 | 对比 xatlas/OptCuts 默认缝位，报告 AO 加权缝长与用户视觉评分（≥20 人主观打分） | 创新 2 |
| E4 耦合验证 | **证明三域联合优于单独优化** | 消融实验：仅几何 / 仅纹理 / 仅力学 / 联合，四组对比 | **创新 2（关键）** |
| E5 强度实验 | 制造接缝的真实效果 | 三组拉伸试件 × n≥5，实测破坏载荷 + 断裂位置分布 | **创新 3（核心）** |
| E6 端到端 | 全流程可用性 | 真实破损件，从扫描到打印成品，记录全流程时间与成功率 | 全部 |
| E7 效率 | 工程可行性 | 10 万/50 万/100 万面模型的耗时与内存 | 工程指标 |

**E3 的"用户视觉评分"很重要**：接缝可见度这类指标最终是给人看的，加入主观盲评（≥20 人，不知情条件下选择更优结果）能显著提升说服力，也容易做。

## 五、创新点的答辩呈现顺序

答辩时间宝贵，建议按"**痛点 → 证据 → 原理 → 数据**"排布，先打出一张最直观的图：

1. **第 1 分钟**：破损模型照片 → 打印失败实物 → "这不是偶然，是常态"
2. **第 2–3 分钟**：竞品失灵矩阵 + **Netfabb 修复后纹理丢失的录屏**（视觉冲击最强）
3. **第 4–6 分钟**：接缝一致性能量框架（一页公式，讲清"三个域是同一件事"）
4. **第 7–9 分钟**：**E5 强度实验数据 + 断裂试件实物**（最硬证据）
5. **第 10 分钟**：产品与商业闭环（见 [docs/04](04-市场与商业模式.md)）

**不要一上来讲公式。** 评委的注意力曲线在前 3 分钟最高，那是留给痛点与视觉冲击的。
