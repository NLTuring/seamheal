# 02 · 技术方案与系统架构

> 这一章要同时说服两拨人：**技术评委**（算法是否成立）和**非技术评委**（学生团队能否实现）。
> 策略：**通用能力用成熟开源库兜底，创新火力集中在接缝域**。绝不承诺"我们要重写一个比 Netfabb 更强的修复器"。

---

## 一、总体架构：四层管线

```
┌──────────────────────────────────────────────────────────────┐
│  L0 输入层   STL / OBJ / PLY / GLB / 3MF / 点云 / STEP(转网格) │
└────────────────────────────┬─────────────────────────────────┘
                             ▼
┌──────────────────────────────────────────────────────────────┐
│  L1 诊断层  Seam-Aware Diagnosis                              │
│  拓扑体检 → 缺陷图谱(Defect Map) → 修复策略规划器              │
│  输出：不是错误列表，而是"哪个洞怎么补"的可执行计划            │
└────────────────────────────┬─────────────────────────────────┘
                             ▼
┌──────────────────────────────────────────────────────────────┐
│  L2 修复层  Hybrid Repair                                     │
│  小缺陷 → 拓扑手术 (Liepa补洞+法线导向边翻转+各向异性重网格)  │
│  大破损 → 隐式场重建 (UDF/SDF + 双轮廓/行进立方体)            │
│  全程 → ★纹理保持：UV调和插值 + 补丁式纹理扩散                │
└────────────────────────────┬─────────────────────────────────┘
                             ▼
┌──────────────────────────────────────────────────────────────┐
│  L3 接缝层  Seam Optimization ★项目招牌                       │
│  (a) 几何接缝：G1/G2 连续化，消台阶、去折痕                    │
│  (b) 纹理接缝：可见度加权缝位优化 + 泊松融合                   │
│  (c) 制造接缝：应力感知分块 + 互锁接头生成 + 打印方向优化       │
└────────────────────────────┬─────────────────────────────────┘
                             ▼
┌──────────────────────────────────────────────────────────────┐
│  L4 输出层  打印就绪文件 + 装配图 + 切片预设 + 可追溯修复报告   │
└──────────────────────────────────────────────────────────────┘
```

**架构的核心设计意图**：L2 与 L3 之间不是"依次执行"，而是共享一个**接缝场（Seam Field）**数据结构——即"模型上哪些位置的属性是不连续的、不连续度是多少"。L2 修复时写入接缝场，L3 优化时读取并修改接缝场。**这是把两个割裂软件流程合成一个优化问题的工程实现方式。**

## 二、L1 诊断层

### 2.1 拓扑体检清单

| 检测项 | 判定方法 | 严重度权重 |
|---|---|---|
| 边界环（孔洞） | 半边结构中无配对半边，绕行成环 | 按环长 × 局部曲率 |
| 非流形边 | 一条边关联面数 ≠ 2 | 高 |
| 非流形顶点 | 顶点邻域不同胚于圆盘 | 高 |
| 自相交 | BVH 加速的三角对相交测试 | 高 |
| 法线朝向不一致 | 相邻面共享边方向一致性传播 | 中 |
| 退化面 | 面积 ≈ 0 / 零长边 / 重复顶点 | 低 |
| 孤立壳 | 连通分量分析，非最大壳处理 | 按体积 |
| 薄壁 / 过薄特征 | 局部厚度场（射线投射或距离场） | 制造域，高 |

### 2.2 从"报错"到"策略"（第一处工程创新）

现有工具给出的是**错误清单**（"发现 37 个孔洞"）。我们给出的是**修复处方**：

```
对每个孔洞 h：
  特征向量 = [环长, 周长/面积比, 边界曲率均值, 边界法线方差,
              周围面片密度, 所在区域厚度, 是否跨特征线]
  → 决策：补洞 / 隐式重建 / 移交人工
  → 若补洞：选择补洞算法与参数（目标边长、特征线约束、UV插值策略）
```

**好处**：技术上是小型分类器（可用规则 + 少量标注微调），工程量小；但对用户价值极大，而且为 L4 的"可追溯修复报告"提供数据。

### 2.3 接缝场（Seam Field）的定义

接缝场的载体：在每条**边**和每个**顶点**上定义属性

```
Edge e  →  is_seam: bool,  discontinuity: {geom, tex, mech},  confidence: float
Vertex v →  uv: vec2,  normal: vec3,  uv_seam_flag: bool,  joint_flag: bool
```

- `geom` 不连续度：两侧面法线夹角 + 位置差
- `tex` 不连续度：两侧 UV 对应的纹素颜色差（接缝可见度的直接度量）
- `mech` 不连续度：该处法向应力方向的层间结合弱化系数

**这个结构是整个项目的数据中枢**，L2 写、L3 改、L4 出报告。建议在论文里明确定义并作为主要贡献之一展示。

## 三、L2 修复层：混合策略

### 3.1 小缺陷——拓扑手术

**补洞**：Liepa 算法（最小面积三角化 + 基于 dihedral angle 的边翻转精修 + 各向同性细分逼近周围平均边长）。
- 优点：快、稳、保留原始面片结构
- 缺点：只对"小且近似平面"的洞有效（文献共识）

**精修**：补完后在补片邻域做**特征感知的各向异性重网格化**
- 特征线提取：二面角阈值 + 主曲率方向
- 重网格化时沿特征线对齐，保证 L3 的几何接缝连续化能落地

### 3.2 大孔洞 / 严重破损——隐式场重建（兜底方案）

技术路线（选用成熟且可实现的组合，而非堆前沿）：

```
输入：破损网格 + 边界约束
  ↓
1. 法线估计与定向（对点云/网格边界）
  ↓
2. 隐式场拟合：UDF（无符号距离场）适合开放表面；SDF 适合需要封闭体
   可选项：
     - 学术级：神经 SDF（如 NeuS/VolSDF 类微调）
     - 工程级：Poisson 重建 / Screened Poisson（Open3D 内置，稳定）
  ↓
3. 等值面提取：Marching Cubes（稳）或 Dual Contouring（保尖锐特征）
  ↓
4. ★边界顶点精确复用：把重建面的边界顶点强制替换为原网格边界顶点
    ← 这一步是避免"修复出新裂缝"的关键，也是文献里明确强调的
```

> **文献支撑点**：2025 年有工作专门用"精确复用边界顶点"来避免裂缝与 T 型接头（MeshFIM 思路），也有工作用"LLM 路由 Marching Cubes / Dual Contouring 以兼顾流形稳定与尖锐特征"（WGS，CVPR 2026 早期）。**我们的取舍：不做神经重建（算力与数据不可控），用 Poisson/UDF + 边界复用 + 特征保持，把可靠性放在第一位。**

### 3.3 ★纹理保持（创新点 1 的技术落地）

这是现有工具的死穴，也是我们最容易做出亮点的部分。

**难点**：补洞产生的新面片没有 UV 坐标，现有软件直接用"无 UV 的面"替换，纹理就丢了。

**方案：三步走**

1. **新面片的 UV 坐标由边界 UV 调和插值生成**
   以孔洞边界的 UV 为边界条件，在补片区域内求解：
   ```
   min ∫_patch ‖∇u‖² dA    s.t. u|_∂patch = u_boundary
   ```
   即调和映射（离散化为稀疏线性系统 `L·u = 0`，边界固定）。**这是一个几百行的实现，学生完全做得到，效果立竿见影。**
2. **纹理内容补全**：调和插值只给出 UV 坐标，纹理内容（像素）需要用图像补全
   - 基线：把补片 UV 区域投影到纹理图，用 **PatchMatch / 快速行进法 (FMM) 图像修复**填充
   - 加分：用扩散模型做纹理补全（可作为二期）
3. **无缝化**：补全区域与原纹理之间做**泊松融合（Poisson blending）**，消除色差硬边
   > 泊松融合在三维纹理接缝上的经典方法（Dessein 等 2014；Gal 等 2010）非常成熟，实现难度低，视觉提升显著。

**量化指标**：修复区 UV 保留率（目标 >99%）、修复区纹理 PSNR（目标 >30 dB）、SSIM。**这两个数字直接对比 Netfabb 的"UV 丢失"，是答辩最有杀伤力的一页。**

### 3.4 学习模块的定位（要说清边界）

**用，但不依赖。** 学习模块承担两件事：

1. **局部几何先验**：图卷积网络在顶点位置与面法线两路上做自监督学习，从**单个输入网格自身**提取先验（不需要大规模配对数据集，参考 2025 TVCG 的自先验思路）
2. **补片候选生成与打分**：对拓扑手术给出的 2–3 个候选补片，用网络打分选出最合理的一个

**关键答辩话术**：我们**不承诺**"用神经网络解决所有破损"，因为那在数据与算力上都不可控。神经模块只做**局部决策与打分**，全局可靠性由几何算法保证。**"不吹牛"反而是可信度的来源。**

## 四、L3 接缝层（项目招牌）

### 4.1 (a) 几何接缝：G1/G2 连续化

**目标**：消除扫描拼接台阶与修复补片痕。

```
1. 定位接缝带（Seam Field 中 geom 不连续度超阈值处）
2. 提取接缝两侧的局部邻域补丁（两片重叠区域的顶点集）
3. 求解约束优化：
   min  Σ_v ‖x_v - x̂_v‖² + α·Σ 边 ‖n_v - n̂_v‖²
   s.t. 接缝处两侧法线一致（G1）
        特征线位置保持不变（硬约束）
4. 用低秩/稀疏求解器（Eigen + CHOLMOD）求解，避免全局重网格化
```

**要点**：只动接缝带，**其余区域一概不动**——这直接回应"自动修复会把模型修变形"的痛点。改完后在 L4 报告中给出"本次修改影响 3.2% 的顶点"这样的可追溯数据。

### 4.2 (b) 纹理接缝：可见度加权的缝位优化

**技术背景**：OptCuts（TOG 2018）是当前公认的 UV 接缝优化 SOTA——在给定失真上界下最小化接缝长度；2025 年前沿开始往**可见度/语义感知**方向发展，即用环境光遮蔽（AO）等把接缝推向遮挡区域。

**我们的做法（两层）**：

1. **缝位优化**：沿用"失真上界约束下的接缝最小化"骨架（可基于 xatlas 结果做后处理，或用 OptCuts 思路自研），但**修改目标函数**，加入可见度项：
   ```
   min  Σ_{e∈seam} [ w_len·len(e) + w_vis·visAO(e) - w_sem·semantic_ok(e) ]
   s.t. 失真 ≤ D_max
   ```
   `visAO(e)` 由预计算的环境光遮蔽得到——**遮挡区域的接缝用户看不到，把缝推到那里等于免费获得视觉质量提升。**
2. **接缝融合**：缝依然会产生，但用泊松融合在纹理空间消掉色差硬边（复用 3.3 的模块）

**工程捷径**：先用 **xatlas** 做基础展开（工业级、快、开源），只把"接缝位置"这一层换成我们的可见度感知优化——研究工作量可控，效果好量化。

### 4.3 (c) 制造接缝：应力感知分块与接头自动生成 ★最大亮点

这是**商业软件完全空白、学术上也很少涉及**的部分。

**Step 1：分块面决策**

```
输入：模型 + 打印方向候选 + 材料参数（PLA/PETG/ABS/树脂）
计算：
  1. 有限元近似应力场（简化：把模型当作各向同性弹性体做粗网格 FEM，
     或直接用切片路径的层间接触面做力学简化模型）
  2. 主应力方向分析 → 识别高应力区与临界截面
  3. 分块面候选生成（平面/柱面切割，需同时满足：）
     - 避开高应力区（或选择与主应力方向成有利夹角）
     - 避开特征线（不能从人脸中间切一刀）
     - 每块尺寸 ≤ 打印机成形空间
     - 每块的打印方向能利用 FDM 各向异性（层线方向避开主拉应力）
  4. 求解分块方案：
     min  Σ_block [ stress_risk(block) + λ·seam_visibility(seam) ]
```

**Step 2：互锁接头自动生成**

在选定的分块面上，自动生成定位与承力结构：

| 接头类型 | 适用场景 | 生成规则 |
|---|---|---|
| 销 + 孔 | 厚壁零件 | 孔径 = f(层高, 喷嘴直径)，配合间隙 ≈ 0.15–0.25 mm |
| 燕尾榫 | 需要自对准与抗拉 | 榫宽与角度由局部壁厚推导 |
| 球窝 / 卡扣 | 免胶装配、可拆 | 需要评估拔模与悬垂 |
| 均摊错位接缝 | **通用推荐** | 把单一截面上的接缝**分散到不同高度/角度**，避免同一截面全断 |
| 加厚加强肋 | 高应力接缝 | 在接缝两侧局部加料（以纹理/外观可接受为约束） |

> **"均摊错位接缝"是接缝强度优化的关键思想**：公开资料显示，采用接缝错位均摊方案后，拼接件强度损失可从 23% 降到 2.5% 以内。我们的贡献是**把这个思想自动化、参数化，并纳入统一接缝能量框架**。

**Step 3：打印方向与切片预设**

- 每块独立做打印方向优化（目标：主拉应力方向与层间结合面夹角最优 + 支撑最少）
- 直接输出 Cura / PrusaSlicer / OrcaSlicer 的 profile，避免第三方切片器"路径丢失、坐标漂移"的问题

**Step 4：强度预测（数字孪生闭环）**

```
切片路径 → 层间接触面积（真实路径面积，非名义面积）
        → FDM 各向异性简化强度模型
          σ_max = f(层间结合面积比, 层间温度史, 材料, 打印方向)
        → 预测接缝处破坏载荷
```

> **注意科学诚实**：预测模型必须有实验标定。**不能只给预测值就宣称准确**。正确做法是：设计一组标准拉伸试件（完整件 / 未处理接缝 / 优化后接缝，各 n≥5），在万能试验机上实测，用实测数据拟合与验证预测模型，报告预测误差。**这组实验本身就是申报书里最硬的内容。**

## 五、技术栈选型（可行性证明）

这一节是为了让评委相信"你们做得出来"。**全部选用成熟开源组件，自研部分集中在接缝域。**

| 模块 | 选型 | 理由 |
|---|---|---|
| 网格数据结构 | **libigl** / CGAL / OpenMesh 半边结构 | 工业级，成熟 |
| 基础几何操作 | **Open3D**（Poisson、MC、法线、配准、可视化） | Python 友好，上手快 |
| 布尔/水密化 | **Manifold** (manifold3d) / ManifoldPlus | 稳定布尔，水密化基线 |
| 修复基线 | **pymeshlab** / MeshFix / meshlab 过滤器 | 现成基线，便于对比 |
| 自研核心 | C++ (Eigen) + Python 绑定 (pybind11) | 性能与开发效率平衡 |
| 优化求解 | Eigen + CHOLMOD / Ceres / IPOPT | 稀疏与非线性优化 |
| UV 展开 | **xatlas**（基础展开）+ 自研缝位优化层 | 不重造轮子 |
| 深度学习 | PyTorch + PyG（图卷积）/ torch-scatter | 主流 |
| 切片与路径 | **CuraEngine CLI** / PrusaSlicer CLI / libslic3r | 可脚本化，用于强度仿真 |
| 前端/插件 | **Blender 插件**（Python API）+ Web (React + Three.js) | Blender 插件易触达用户 |
| 强度实验 | 万能试验机（借材料/机械学院实验室）| 或委托第三方检测 |

**团队技能门槛评估**：核心研发需要"计算几何 + C++ + Python + 深度学习 + 3D打印工艺"的组合。这个组合对本科生偏难。按 **6–8 人团队规模**测算：算法组 2 人、学习组 1 人（可并入算法组）、工程组 2 人、制造与实验组 1 人、商业组 1–2 人，全队一人多岗。因此**团队至少需包含 1 名计算机图形学方向研究生**，且必须有一位懂几何处理的指导老师。**这个风险不要藏，申报书里要通过团队配置来正面回应。**

## 七、本阶段待验证的技术假设

- [ ] 调和插值 + 泊松融合的纹理保持方案，在带 UV 的破损模型上实测 PSNR 提升幅度
- [ ] Poisson 重建 + 边界顶点复用，能否稳定避免新裂缝（需要在 100+ 破损模型上批量测试成功率）
- [ ] 简化 FEM 应力场在消费级硬件上的计算耗时是否可接受（目标：50 万面 <3 min）
- [ ] CuraEngine CLI 能否稳定输出可靠的层间接触面积数据
- [ ] 万能试验机的可及性与试件打印成本（需早确认，这是 P3 的前置条件）
