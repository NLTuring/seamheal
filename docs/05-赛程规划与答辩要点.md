# 05 · 赛程规划与答辩要点

## 一、先定赛道（这一步错了，后面全白做）

"挑战杯"是**两个不同的比赛**共用一个品牌，材料和评审逻辑完全不同：

| | **大挑**（课外学术科技作品竞赛） | **小挑**（中国大学生创业计划竞赛） |
|---|---|---|
| 举办节奏 | **奇数年**（2027 年为下一届，届数以官方通知为准） | **偶数年**（2026 年为第十五届） |
| 核心材料 | 作品实物 + 学术论文 + 申报书 | 商业计划书 + 答辩 |
| 作品类别 | 自然科学类学术论文 / 哲学社会科学类社会调查报告 / **科技发明制作 A 类、B 类** | 按产业赛道划分（先进制造、新一代信息技术等） |
| 评审关注 | **科学性、先进性、现实意义**；技术原创性 | **商业价值、市场前景、团队、落地转化** |
| 适合本项目的类别 | **科技发明制作 A 类**（科技含量高、制作投入较大） | 赛道建议：**先进制造** 或 **新一代信息技术**（人工智能/基础软件） |

**本项目的判断**：
- 这是一个**技术驱动型**项目，天然属于**大挑·科技发明制作 A 类**。
- 今天是 2026 年 10 月，**2026 小挑（第十五届）已进入国赛阶段**，新周期应从 **2027 年大挑**起步——这个时间点正好是启动期，时机合适。
- 如果目标其实是 2028 小挑，则必须在现有技术方案基础上补一整套商业计划书（[docs/04](04-市场与商业模式.md) 即为该用途准备）。

> ⚠️ **必须第一时间确认**：向学校团委确认今年/明年本校认定的是哪个比赛、参赛类别、截止时间。不同学校的时间节点与要求差异很大，**一切以学校团委通知和国赛组委会正式文件为准**。

## 五、答辩预设问答（务必逐条准备答案并演练）

### Q1：你们凭什么比 Netfabb / Magics 这些工业软件强？

**答**：我们不试图在所有维度上超越它们。**通用几何修复我们用成熟开源组件（libigl/Open3D/Manifold）做到"够用"，把创新集中在它们忽视的两个环节：修复后的纹理保持，以及分块打印的接缝强度。**
这两个环节的失败我们都有实测录屏佐证：Netfabb 修复后 UV 丢失导致纹理损毁；分块接缝强度损失 23.3% 且无任何工具提供自动化方案。
**我们不是更好的通用修复器，我们是唯一处理接缝的工具。** 这是定位差异，不是能力攀比。

### Q2：你们说 Netfabb 修完会丢 UV，有证据吗？

**答**：有。我们准备了三个带纹理的破损模型做对照测试，全程录屏，原始文件和修复后文件都已存档。请看这段 40 秒的录屏。
（**必须真的做过这个测试并把文件留好。这是最容易被追问的一条。**）

### Q3：深度学习部分是不是只是调库？有没有真创新？

**答**：我们**主动限制**了神经模块的职责范围——只做补片候选打分与局部几何先验，全局可靠性由几何算法保证。
原因很明确：**用神经网络端到端解决严重破损，在数据和算力上对学生团队不可控，而且不可解释、不可追溯。**
我们的真创新不在"用了什么网络"，而在于**问题的建模方式**：把修复、参数化、分块统一到一个接缝能量框架下。**创新在问题定义，不在网络层数。**

### Q4：强度实验的样本量够吗？数据可靠吗？

**答**：每组 n≥5，三组共 ≥15 个标准拉伸试件，同一台设备、同一批耗材、同一打印参数，记录破坏载荷与断裂位置。
我们同时报告**均值、标准差和断裂位置分布**——如果优化有效，断裂位置应该从接缝转移到母材，这个分布变化比单纯的载荷数字更有说服力。
（**若尚未完成实验，如实说明进度并给出已完成的部分数据，绝不编造。**）

### Q5：如果 Autodesk 或 Materialise 明天加了这个功能怎么办？

**答**：单点技术优势确实会被削弱，所以我们不打算靠单点技术长期立足，而是建立三层壁垒：
① **数据壁垒**：免费版回流真实缺陷数据 + 我们独有的打印强度实验数据库，这是闭源桌面软件拿不到的；
② **生态壁垒**：与切片器和扫描设备厂商深度集成，嵌入硬件工作流后替换成本极高；
③ **标准壁垒**：通过 SeamBench 和接缝强度指标，让"接缝质量"这个概念和我们绑定。
**诚实说**：真正的护城河是时间——我们必须在 12–18 个月内拿下垂直行业标杆客户。

### Q6：三个域的统一能量框架，会不会只是概念包装？

**答**：判断标准很明确——**存在耦合吗？** 如果只优化一个域就能同时满足三个域，那我们的框架就是包装。
我们做了消融实验（仅几何 / 仅纹理 / 仅力学 / 联合优化），结果显示：为了力学强度在接缝处局部加厚，会改变局部曲率进而重新分配 UV 失真，单独优化纹理域会导致接缝处拉伸加剧；而单独优化力学会导致特征线被破坏，纹理错位。
**只有联合求解才能同时满足，这就是耦合的证据。**

### Q7：和开源方案（MeshFix + pymeshlab + xatlas）拼一拼有什么区别？

**答**：直接拼装能做出一个"能跑的修复器"，事实上这也是我们 P0 阶段的基线。
但拼装方案有三个跨不过去的断层：**① 修复丢失 UV 与纹理；② 各模块之间无信息传递，修复结果无法指导接缝优化，接缝方案也无法反馈给修复；③ 完全没有制造域，不能分块、不能生成接头、不能预测强度。**
我们的贡献恰恰是打通这三个断层，而不是重写已有的轮子。

### Q8：团队里有懂计算几何的人吗？

**答**：（如实回答，并给出弥补方案）
计算几何门槛确实高。我们采用 6–8 人（7 人配置、一人多岗）的精干团队，其中算法组配置了 **1 名图形学方向研究生负责核心算法 + 1 名相关方向指导老师把关 + 通过成熟开源库降低工程门槛。**
同时我们采用"**通用能力用库、创新集中在接缝域**"的技术策略，正是为了把有限的人力集中在最有价值的环节。

### Q9：数据从哪来？合规吗？

**答**：三类来源：① 公开数据集（Thingi10K/ABC/Objaverse）用于合成缺陷评估；② 程序化注入缺陷生成真值数据；③ 与打印服务商合作获取真实破损件，**签署数据使用协议**。
免费版仅收集用户明确授权的**匿名化几何统计特征**，不采集模型内容本身，并提供完全离线的本地运行模式。

### Q10：这个项目的科学问题到底是什么？

**答**：在破损三维模型的修复与分块制造中，**如何建立一个跨几何、纹理、力学三个域的统一接缝不连续度度量，并在该度量下求解"既保真又保强度"的最优修复与分块方案。**
拆成三个子问题：**度量问题**（接缝质量目前只有定性描述，缺乏可计算指标）、**求解问题**（保真度、纹理连续性、力学强度三者冲突，是带拓扑约束的多目标优化）、**验证问题**（现有 CD/Hausdorff 指标无法回答"打印出来会不会断"，需要建立模型到力学性能的可信映射）。
这三个子问题分别对应我们的四条创新点。

### Q11：能保证 100% 水密吗？失败怎么办？

**答**：不能承诺 100%，任何工具都不能——**2025 年的文献仍把"严重破损输入"列为开放挑战**。
我们的设计是**分级降级策略**：小缺陷走拓扑手术（成功率高、保形好）→ 大破损走隐式重建（成功率高、形状自由度大）→ 仍失败则明确标记并**移交人工**，同时给出诊断信息与建议参数。
关键是**每一步都可追溯**，输出报告说明改动了哪些区域、影响了多少顶点，而不是像现有工具那样"黑箱修完、不知改了哪里"。

### Q12：需要什么硬件？成本高吗？

**答**：修复与接缝优化是**几何算法为主**，CPU 即可运行，消费级笔记本可用；神经模块只在需要时调用，不强依赖 GPU。云 API 版本才需要服务器算力。
我们的目标性能是 **50 万面模型 3 分钟内处理完成**，这比 Magics 处理数千万面需 64GB 内存的要求低得多。

### Q13：项目的下一步计划是什么？

**答**：① 完成分块接头的强度实验，把强度预测模型的误差标定到 15% 以内；② 把与切片器的集成从 Cura 扩展到 PrusaSlicer 与 OrcaSlicer；③ 在医疗器械场景（牙科导板、外固定支架）做合规性验证；④ 公开 SeamBench 并推动接缝强度指标成为行业参考。

## 六、需要你确认的事项（影响后续所有材料的形态）

1. **打哪个比赛**：2027"大挑"（科技发明制作 A 类）还是 2028"小挑"？—— 决定是学术材料还是商业计划书为主。

3. **团队构成**：已定 6–8 人（7 人配置，一人多岗）。仍需确认学历层次（决定分到专科组/本科组/研究生组，评审标准不同），以及队内是否有图形学方向的同学与指导老师。
4. **设备资源**：能否借用万能试验机（材料/机械学院实验室）？这是创新点 3 的前置条件，**越早确认越好**。

6. **是否已有合作企业**：3D 打印服务商、文博单位、医疗器械厂商——直接影响用户证明材料的获取难度。

## 七、接下来最该做的三件事（按优先级）

1. **做竞品实测并录屏**：Netfabb / Magics 修复带 UV 的破损模型，记录 UV 与纹理丢失情况。**这是整个项目论证的基石，也最容易被评委追问，必须最先做。**
2. **跑通基线并建立数据集**：用 Open3D/libigl + MeshFix + SPSR 跑通修复流程，从 Thingi10K 抽样统计破损率。有了基线和数据，才能谈对比。
3. **确认试验机与打印资源**：创新点 3 的全部价值依赖真实力学实验，这是唯一一个"拿不到设备就做不成"的环节，必须最早锁定。
