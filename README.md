# 愈缝 SeamHeal
## 面向数字制造的 3D 模型智能修复与接缝优化引擎

**当前软件：** [本地工作台 v0.2](workbench/README.md) 已实现几何修复、纹理补全和制造准备流程。下文为立项方案，强度、效率和市场数字属于待验证的研究目标或论证内容，不能视为当前软件的实测承诺。

## 获取与运行

模型（BLEND / GLB）和素材包 ZIP 使用 [Git LFS](https://git-lfs.com/) 存储。安装 Git LFS 后，在 PowerShell 中运行：

```powershell
git lfs install
git clone https://github.com/NLTuring/seamheal.git
cd seamheal
git lfs pull
.\workbench\start.ps1
```

首次启动需要 Python 3.11+、Node.js 22.12+ 和网络连接，用于安装依赖及构建前端。详细操作见[工作台说明](workbench/README.md)。直接下载 GitHub 源码 ZIP 时可能只包含 LFS 指针文件，建议使用上述克隆方式获取完整模型。

> 一句话：把一个破的、不能打印的 3D 模型丢进去，3 分钟后拿到一个**能直接打印、纹理不丢、接缝处不断裂**的模型——而现有方案需要工程师手工折腾两小时，且修完就破相。

## 一、我们到底在解决什么

整个 3D 数据链路里存在一个被所有工具忽略的 **信息断点**：**接缝**。

模型在生成与制造过程中，会在四个环节产生接缝，而这四个环节分属不同软件、彼此不通信：

| 接缝类型 | 产生环节 | 后果 | 现在谁来管 |
|---|---|---|---|
| 重建接缝 | 多视角扫描配准拼接 | 几何台阶、纹理色差 | 扫描软件（只做简单融合） |
| 修复接缝 | 孔洞补片与原网格边界 | 补丁痕、法线断裂 | 修复软件（不关心） |
| 参数化接缝 | UV 展开切割 | 纹理拉伸、可见硬边 | 手工刷/学术算法（不落地） |
| **制造接缝** | 分块打印装配 | **强度下降 23%，最弱点** | **没人管，靠工程师经验** |

**本项目的核心判断：这四类接缝在数学上是同一件事——接缝两侧的属性不连续。** 因此可以用一个统一的能量框架同时优化几何、纹理、力学三个域。

这就是我们和所有竞品的根本区别：**别人只优化一个域，我们优化接缝本身。**

## 二、统一理论内核：接缝一致性能量

定义接缝曲线/曲面 Γ，其上的总不连续能量：

```
E_seam(Γ) = ∫_Γ [ w_g·‖Δn‖²  +  w_p·‖Δx‖²  +  w_t·‖Δc‖²  +  w_m·‖Δσ‖² ] ds
             几何法线不连续   位置不连续    颜色不连续    力学不连续
```

总优化目标：

```
min  E_seam + λ·E_fidelity + μ·E_manufacturability
 s.t. 拓扑合法（流形/水密/定向一致）、最小壁厚、自支撑角
```

- `E_fidelity`：保真度——不许把模型修变形、不许丢纹理
- `E_manufacturability`：可制造性——自支撑角、最小壁厚、FDM 各向异性
- 四个权重 `w_*` 决定"这条缝该往哪挪、怎么治"

**这个框架把"修复"和"接缝优化"从两个割裂的软件功能，变成一个连续优化问题。** 这是项目的立论基础，也是申报书里最该讲清楚的一段。

## 三、产品形态（三层，逐层放大价值）

| 层 | 形态 | 用户 | 价值 |
|---|---|---|---|
| L1 内核 | 几何处理引擎（C++/Python，可作 SDK） | 设备厂商、平台方 | 被集成 |
| L2 工具 | Blender 插件 + 独立 GUI + 云 API | 打印服务商、工作室、创客 | 直接付费 |
| L3 闭环 | 分块打印方案生成 + 强度预测 + 打印就绪文件 | 医疗、工业、手办 | 高客单价 |

**杀手场景（答辩现场演示用）**：AI 生成模型 → 一键可打印。
TripoSR / InstantMesh / MeshGPT 这类文生 3D 很火，但生成的模型绝大多数不能直接打印（非水密、法线乱、壁太薄）。做一个"AI 模型打印就绪化"插件，蹭 AIGC 热点、用户基数巨大，同时技术难度正好在我们能力范围内。**这是最佳切入滩头。**

## 四、四条创新点（每条都有对标物和可测指标）

1. **纹理保持的联合修复** —— 对标 Netfabb/Magics（修复即丢 UV），指标：修复区 UV 保留率、纹理 PSNR
2. **三域统一接缝能量框架** —— 对标 OptCuts/Autocuts（只管 UV 缝）、商业软件（不管缝），指标：接缝处法线角差、接缝可见度
3. **应力感知的分块与互锁接头自动生成** —— 对标人工经验，指标：接缝强度保持率（从 77% 提到 95%+）
4. **SeamBench 基准与可复现评测协议** —— 对标 Thingi10K/ABC（无接缝标注），提供带接缝缺陷标注数据集 + 6 项指标
