# 愈缝 SeamHeal · 本地工作台 0.2

可运行流程：导入/选择构件 → 网格诊断与清理 → 局部补洞和接缝优化 → 纹理选区补全 → 打印几何检查与分块装配 → 导出与历史恢复。

## 启动

在项目根目录运行：

```powershell
.\workbench\start.ps1
```

打开 <http://127.0.0.1:8765>。首次运行需要 Python 3.11+；需要构建前端时还需 Node.js 22.12+。首次安装依赖需要网络，安装后模型处理在本机进行。脚本按 requirements 文件指纹检查依赖变化，旧环境升级会补装新增依赖。

- `-NoBrowser`：只启动服务。
- `-Rebuild`：重新安装前端锁定依赖并构建。
- 已启动的本地服务会被复用；修改 Python 代码后需重启服务。
- 日志：`runtime/server.log`、`runtime/server-error.log`。

若需要在前台启动、用 Ctrl+C 停止，请先保证 8765 端口空闲，然后在 `workbench` 目录执行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8765
```

## 已实现的功能

| 功能 | 当前实现 |
| --- | --- |
| 模型导入 | GLB、STL、OBJ、PLY；模型目录持久化；从列表移除时保留源文件 |
| 三维视图 | 旋转、平移、缩放、复位、全屏、线框、孔洞轮廓、补片接缝；原始/结果/完整基准及双视图 |
| 多构件场景 | 整景直接诊断、勾选多个局部构件后一次修复；也可下拉选择单构件。连续处理保留其他构件、世界变换和前一步结果 |
| 几何修复 | 检查边界、退化面、非流形边和面朝向；清除重复/退化面并统一朝向；局部曲面补洞和新 UV 插值 |
| 接缝优化 | 测量原面与补片的二面角及补片 UV 各向异性；只移动新增顶点；通过改善判定才接受候选结果 |
| 纹理补全 | 在基色贴图上拖动矩形选区，以 OpenCV 局部插值补全像素；保留选区外像素、透明通道、其他 PBR 贴图和原 UV |
| 基准测量 | 固定种子的双向采样点到三角面距离，输出平均/均方根/抽样最大距离（mm） |
| 打印检查 | 外形、体积、闭合/朝向、打印空间、抽样壁厚、悬垂比例及限定规模的非相邻面相交检查 |
| 制造分块 | 对适合的封闭实体做真实布尔切分，支持平面分块和滑入式燕尾，测量间隙并检查闭合与重叠 |
| 燕尾试件 | 独立生成可调宽/深/高、燕尾角、间隙的公母试件，无需先选择场景构件 |
| 结果管理 | 自动保存每次处理，历史恢复与连续处理；GLB、毫米 STL、JSON 报告及 ZIP 打包下载 |

修复内核不读取完整基准、损坏面索引或预设修复结果。完整基准仅用于事后对比与误差测量。原始素材包不会被改写。

## 推荐演示流程

1. 选择「花枝彩绘墙板」，诊断并执行局部修复。检查边界边变为 0，切换前后对比。
2. 选择「曲面瓦顶」，执行修复，查看接缝角度、开启「补片接缝」，运行「与完整基准测量比较」。
3. 打开「纹理补全」，在贴图上框选小区域并补全；原样本纹理是完整的，此操作可用于验证局部编辑。真实缺失像素需导入带破损贴图的 GLB。
4. 选择「樱庭完整场景」，直接点击「开始网格诊断」。检查全部 56 个构件后，默认勾选破损墙板和屋面，点击「执行局部修复」一次处理这两件并保留完整场景。其他开放装饰表面与非流形构件会列为待复核；也可在处理范围中选择单构件继续处理。
5. 导入实体 STL，在「制造准备」中检查尺寸、选择切分轴和装配间隙，生成分块；也可直接展开「参数化燕尾试件」。
6. 下载 ZIP。GLB 保留场景与可用纹理；STL 用于切片软件。通过「历史记录」恢复任一次保存结果。

## 单位、范围与输出

- GLB 使用米、Y 轴向上，要求贴图/缓冲区内嵌。
- STL / OBJ / PLY 按导入选项解释 mm / cm / m，默认 mm；输入约定为 Z 轴向上，自动转为 GLB 坐标。
- STL 导出为毫米、Z 轴向上，不含纹理和颜色。分块与打印检查中的 X/Y/Z 均为打印坐标。
- 单文件 ≤32 MB；场景 ≤128 个网格构件、50 万三角面，单构件 ≤60 万顶点；最多保留 100 个活动导入条目。
- OBJ 按几何导入，外部 MTL/贴图不读取；带纹理数据请使用内嵌 GLB。
- 纹理选区 ≤图像的 30%，且 ≤50 万像素；图像总像素不超过 4096²。
- 简单边界环最多 2048 个顶点。严重非流形、分叉边界、跨 UV 接缝和无法可靠补齐的区域返回原因。
- 每次操作保留 `parent_result_id`（几何/纹理连续处理）、时间、来源、输入/输出 SHA-256、实际检查和算法限制。
- 几何/纹理输出 GLB 包含整个场景，STL 导出当前处理构件；分块输出导出各独立部件。ZIP 包含模型、报告、STL，纹理补全包另含基色 PNG。

## 验证

在 `workbench` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

当前 53 项几何、纹理、制造和 API 测试通过，包含 OBJ/PLY/STL 单位转换、场景连续修复保持其他构件、模型目录重载、旧版结果兼容。另覆盖整景局部修复、其他 54 件几何/UV/变换保留、批处理失败不保存部分结果，以及多材质构件标识的稳定性。测试使用临时输出目录，保留实际工作数据。

真实浏览器检查需要 Playwright Python 包和本机 Edge/Chrome，先启动服务，再运行：

```powershell
python tests/browser_smoke.py
```

覆盖修复、纹理选区、场景连续处理、参考测量、历史恢复、STL 导入、打印检查、燕尾生成、ZIP/STL 读取和窄屏布局。检查记录与截图保存于 `runtime/qa/`。浏览器验收会生成真实历史和一个测试导入条目；从列表移除测试模型不会删除其文件。重启服务后，可运行 `python tests/browser_persistence.py` 检查目录/历史恢复和历史下载，并从列表移除该测试条目。

本次实际浏览器验收无 JavaScript 错误，窄屏无横向溢出；服务重启后的模型与历史恢复、ZIP 下载、归档保留原文件均通过。屋面样本接缝平均角差从 3.0457° 降至 0.4929°（318 个新增顶点移动）；这是该样本的局部几何测量，不是任意模型的效果保证。

针对樱庭整景和字体的浏览器回归：`python tests/browser_scene.py`，覆盖默认整景诊断/修复、ZIP、历史恢复，以及 390–1440px 宽度的可读性与布局。

界面主要正文与按钮为 15–16px，次级说明为 13–14px；窄屏使用重排布局。

前端构建：在 `web` 目录执行 `npm ci`、`npm run build`，包含 TypeScript 检查。

| 路径 | 内容 |

| `engine/mesh_repair.py` | 拓扑诊断、缺陷清理与局部补洞 |

## 能力边界与后续研究

当前完成了本地工作台的上述操作链路；项目立项文件中的研究目标需要继续实验验证：

- 纹理补全基于邻域图像插值，不能保证还原真实原始花纹，尚无训练式语义/大范围重建。
- 新 UV 与局部补洞适用于边界约束明确的局部缺陷；任意大孔洞、跨 UV 接缝和复杂多材质连续优化仍需专门算法。
- 接缝角度改善是几何测量，不代表受力性能改善；尚未实现 FEM、应力驱动分块或材料/打印参数标定的强度预测。
- 壁厚最多抽样 96 处，不是全表面的最小厚度保证。非相邻面检测最多 5 万三角面、2 万候选面及 3 秒预算；共享位置顶点的面重叠不在范围内，未完成会标为部分/未检查。
- 「已检查项通过」不等于打印成功或强度认证，仍需切片预览和实际试装。悬垂提示不自动生成支撑。
- 布尔分块使用部件颜色，暂不保留输入 UV/纹理。燕尾要求足够、贯通的实体安装区，不适用于任意薄壁曲面。
- 基准距离是固定种子抽样结果，抽样最大值不是严格 Hausdorff 距离；当前样本不能代替大规模真实破损数据评测。
